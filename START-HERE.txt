CIS LEDGER
==========

Invoices and CIS records for UK construction subcontractors
(electricians, plumbers, carpenters, scaffolders, groundworkers).

This is not HMRC-recognised tax software. It does not file CIS300
or Self Assessment. Your books stay in this folder, in cis-ledger.json.
Not the cloud. Not the browser store.

START IN 5 STEPS
----------------
1. Unzip so you have a folder called CIS-Ledger.
2. Windows: double-click Start-CIS-Ledger.bat
   Mac:     double-click Start-CIS-Ledger.command
   Linux:   see INSTALL.md (run start-cis-ledger.sh)
3. If it says Python is missing:
   install Python 3 from https://www.python.org/downloads/
   On Windows, tick "Add python.exe to PATH", then try step 2 again.
4. Your browser should open http://127.0.0.1:8080/
   Click "Open the app".
5. Leave the starter window open while you use CIS Ledger.
   Close that window when you have finished.

YOUR BOOKS
----------
The whole book (profile, contractors, invoices, PIN, next invoice
number) is saved as cis-ledger.json in this CIS-Ledger folder, next
to this file. Clearing the browser does not wipe it. Deleting that
JSON file does. Keep a JSON backup from Settings anyway.
