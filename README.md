# Working CIS Ledger

Working copy of **CIS Ledger v1.1.4** (1 September 2026).

Invoices and CIS records for UK construction subcontractors. Local-only. MIT licensed.

**Not HMRC-recognised tax software.** It does not file CIS300 or Self Assessment.

## Source of this tree
